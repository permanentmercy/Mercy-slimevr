# 工程验收与技术状态验证记录 (v2 更新)

> **当前结论**：模型代码、分层检查点系统与流式 ONNX 单线程 CPU 推理耗时（0.40 ms / P95: 0.54 ms）工程验收通过；**真实动捕追踪精度、物理触地真值与整机端到端延迟尚未实机验收**。不得将合成仿真指标混淆为实机达标。

## 一、 v1 阶段工程基线与验证结果

### 1. 已验证通过项目
- **工程合规与数学法则测试 (`python -m ai_corrector.corrector.acceptance`)**：
  - 因果时序隔离（无未来帧泄露）、逐帧流式状态与全序列前向传播等价性。
  - 四元数超球面单位归一化、$\pm 8.0^\circ$ 生理硬限幅、四元数右乘残差目标（$q_{\text{clean}} = q_{\text{raw}} \otimes \Delta q$）。
  - 可靠性门控全修正与零退避旁路、有限梯度、符号不变性、检查点往返一致性。
- **全量 AMASS 合成加噪流水线**：
  - 接入 SMPL-H 几何模型，同步 38 个高质量子集（16,785 条有效序列，165,229 个时空切片窗口，330.5 万帧动作流）。
- **CSTN 模型多任务训练与轻量化导出**：
  - RTX 4070 AMP 混合精度训练收敛（最优综合 Val Loss 0.058576，合成标签残差角误差 0.1533°，合成接触 F1 95.80%）。
  - 单线程 CPU ONNX 导出实测耗时：**均值 0.40 ms，P95 0.54 ms**（远优于 $\le 4.50$ ms 性能预算）。
  - 本地权重全生命周期管理系统（`checkpoints/best/`, `latest/`, `top_k/`）及脱水瘦身验证通过。

### 2. v1 仿真分数的局限性与指标分离声明
必须明确：**已有仿真分数不能直接代表真实追踪精度**：
1. **训练残差角误差 (0.1533°)**：仅衡量模型输出增量与加噪合成标签的拟合程度；小样本对比实验显示，模型残差角相对原始输入的改善仅约 2.6%，且未反映前向运动学（FK）骨架位置误差与无漂移时的误修正率。
2. **触地分类 F1 (95.80%)**：此指标目前基于脚踝空间速度阈值（$< 0.35\text{ m/s}$）的启发式合成代理标签，**并非真实物理传感器触地真值**。
3. **置信门控标签**：v1 训练时门控目标全置为 1，未表达“预测修正是否真实降低姿态误差”的实际收益。
4. **输入特征定义**：修正文档中关于“135 维外加 4 维足端特征”的描述冲突，明确 v1 为 135 维。

## 二、 v2 阶段核心演进与待验收项目

项目当前正式推进至 **v2 目标架构（4 个下肢 IMU + VD 上身视觉参考）**：

### 1. v2 契约与环境定义
* **输入契约**：固定为 $X[B, T, 124]$，由 8 路组成（HMD 17 维、VD 胸部 17 维（可缺省）、VD 双上臂各 17 维、双大腿与双小腿 IMU 各 14 维）。
* **输出契约**：4 处下半身关节点四元数残差 `dq[B, T, 4, 4]`、门控 `gate[B, T, 4]` 和双脚触地概率 `contact[B, T, 2]`。
* **服务端影子模式**：在 `Tracker.tick()` 与 `HumanPoseManager.update()` 之间接入 60Hz 采样与进程内 ONNX Runtime 推理，默认只记录修正候选，不驱动 Avatar。

### 2. 当前尚未实机验收的项目
* **整机全链路端到端延迟**：包括 IMU 采样、网络传输、服务端数据适配、ONNX 推理至求解器输出的全链路延迟（是否满足 $\le 20.0$ ms 门槛需全链路测定）。
* **下肢偏航误差削减率**：在 0、1、3、10°/min 真实漂移下的削减率。
* **零漂移场景误修正率**：在纯净无漂移运动下，模型不得带来可测的骨架劣化。
* **目标硬件实测**：因当前无目标实机设备，本阶段只交付合成回放与影子路径验收；真实设备验证待硬件就绪后在影子模式中采集比对。
