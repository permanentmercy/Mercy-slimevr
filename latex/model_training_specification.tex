\begin{abstract}
针对基于 SlimeVR 的 6 轴惯性测量单元（IMU，LSM6DSV）全身动作捕捉中偏航角（yaw）积分漂移、传统几何求解器缺乏时空统计先验以及下半身运动估计中的足部滑步（foot skating）与悬空穿模等问题，本文档确立了服务器端神经网络残差校正器的模型训练、开源基准选型、数据集流水线与技术指标体系。为解耦算法研发与物理硬件制作周期，技术路线采用离线数据驱动与仿真加噪方案：以 AMASS 高精度光学动捕数据为基准真值，结合传感器物理特性注入陀螺仪零偏游走与高频噪声，构建全合成配对训练集；整合 HMD-Poser（CVPR 2024）的因果时空网络、PIP（CVPR 2022）的物理足部触地判别机制与 AvatarPoser（ECCV 2022）的数据工程管线，构建紧凑型多任务因果时空网络模型。该架构将单帧推理时延约束于 2.0\,ms 以内，以平均关节位置误差（MPJPE）$< 45$\,mm、偏航漂移抑制率 $> 88\%$、足部触地判别 F1 分数 $> 93\%$ 作为离线训练收敛与验证指标。
\end{abstract}

\subsection{配套辅助工具}

除核心深度学习模型外，工程链路还依赖以下 3 个开源组件实现环境适配与数据流打通：
\begin{enumerate}
    \item \textbf{Virtual Desktop Body Tracking Configurator (VDBTC)}：由 DenTechs 开发的开源 SteamVR 配置工具。用于关闭 Virtual Desktop 算法推测的下半身虚拟追踪点（Generative Legs），仅保留头显摄像机直接追踪的胸部和双肘（Top Body Only），避免下半身绑定冲突。

    \item \textbf{SlimeVR Feeder App 与 OpenVR 驱动}：随 SlimeVR 官方安装包附带的桥接组件，通过命名管道获取 SteamVR 虚拟追踪器位姿，将 Quest 3 视觉估计数据输入 SlimeVR 服务端求解器。
\end{enumerate}

% ==================== 二、离线训练与评测数据集方案 ====================
\section{离线训练与评测数据集方案}
\label{sec:datasets}

为确保在物理硬件采购、焊接及固件调试期间能够独立推进算法开发，模型训练与性能验证基于离线动捕数据集与物理仿真管线开展。

\subsection{数据集选型}

\begin{enumerate}
    \item \textbf{AMASS (Archive of Motion Capture as Surface Shapes)} —— \textbf{基础动作训练集}
    \begin{itemize}
        \item \textbf{数据说明与格式}：Max Planck Institute（MPI）发布的标准化人体动捕数据库（\url{https://amass.is.tue.mpg.de/}），数据为统一的 \texttt{.npz} 文件，包含 60\,Hz/120\,Hz 的 SMPL-H 关节旋转矩阵、全局平移量与人体体型参数（$\beta$）。
        \item \textbf{代表性子集选取}（总数据量约 2.9\,GB，避免全量下载的存储与解析开销）：
        \begin{itemize}
            \item \texttt{CMU}（约 1.5\,GB）：涵盖日常步态、下蹲、转身、起坐等多种动作序列；
            \item \texttt{HDM05}（约 800\,MB）：包含高精度标准化动作采样，动作分类结构规范；
            \item \texttt{BMLrub}（约 600\,MB）：包含较多平地足底周期性支撑与摆动数据，适用于训练足部触地判别。
        \end{itemize}
    \end{itemize}

    \item \textbf{DIP-IMU Dataset} —— \textbf{实测传感器泛化评估集}
    \begin{itemize}
        \item \textbf{数据说明与规模}：MPI 随 SIGGRAPH 2018 论文开源（\url{https://dip.is.tue.mpg.de/}），约 1.5\,GB。
        \item \textbf{评估价值}：该数据集记录了 10 名受试者佩戴 17 颗 Xsens 工业级 IMU 传感器的原始数据，并同步记录了毫米级 Vicon 光学真值。用于在无实体硬件条件下，评估模型对真实传感器噪声与软组织运动伪影的泛化能力。
    \end{itemize}
\end{enumerate}

\subsection{人体模型参数包依赖}
动捕数据正向运动学（FK）计算依赖 SMPL-H 基础网格参数文件：
\begin{itemize}
    \item 访问 MANO 官网（\url{https://mano.is.tue.mpg.de/}），下载所需模型包 \texttt{SMPL+H model (with DMPLs)}；
    \item 解压得到 \texttt{smplh/male/model.npz} 与 \texttt{smplh/female/model.npz}，放入数据处理脚本对应的 \texttt{support\_data/body\_models/} 路径下。
\end{itemize}

\subsection{离线合成加噪训练样本生成流程}
通过前向运动学仿真，从 AMASS 纯净骨架序列生成模拟 Quest 3 上半身锚、6 轴带漂移 IMU 下半身以及足部触地标签的配对样本。完整生成步骤定义如下：

\begin{enumerate}
    \item \textbf{参考基准提取}：提取头部关节世界位姿作为虚拟头显观测基准：
    \[
    T_{\text{head}} = (q^*_{\text{head}}, x^*_{\text{head}})
    \]
    该观测是合成训练中的理想参考，不代表真实 HMD 或 VD 身体关节观测无误差。训练应注入参考位姿噪声、时延、短时丢失和重定位扰动，并分别模拟各下肢节点的独立漂移；理想参考仅用于消融对照。
    \item \textbf{足部触地标签标注}：根据左右脚踝位移变化率计算线速度 $v_{\text{foot}, t} = \|x^*_{\text{foot}, t} - x^*_{\text{foot}, t-1}\| / \Delta t$，并结合脚底离地高度 $z_{\text{foot}, t}$，设定触地状态标签准则：
    \[
    C^*_t = \begin{cases}
    1, & \text{if } v_{\text{foot}, t} < 0.1\,\text{m/s} \quad \text{且} \quad z_{\text{foot}, t} < 0.03\,\text{m} \\
    0, & \text{otherwise}
    \end{cases}
    \]
    \item \textbf{传感器偏航积分游走注入}：针对下半身关节点（骨盆、大腿、小腿），根据 MEMS 陀螺仪的角随机游走系数 $\sigma_{\text{arw}}$ 与零偏漂移项 $b_{\text{gyro}}$，按步长 $\Delta t$ 累积偏航漂移角：
    \[
    \psi_t = \psi_{t-1} + b_{\text{gyro}} \Delta t + \sigma_{\text{arw}} \sqrt{\Delta t} \cdot \epsilon_t, \quad \epsilon_t \sim \mathcal{N}(0, 1)
    \]
    将漂移扰动叠加至纯净局部四元数 $q^*_i$：
    \[
    q^{\text{corrupt}}_{i, t} = \text{Rot}_z(\psi_t) \otimes q^*_{i, t}
    \]
    同时向线加速度引入高斯白噪声与动态离心扰动：$a^{\text{corrupt}}_{i, t} = a^*_{i, t} + \delta a_{\text{dyn}}$。
    \item \textbf{四元数残差回归目标构建}：监督目标定义为纯净旋转四元数相对于扰动旋转四元数的增量残差：
    \[
    \Delta q^*_{i, t} = (q^{\text{corrupt}}_{i, t})^{-1} \otimes q^*_{i, t}
    \]
    \item \textbf{时序滑动窗口封装}：以时间步长截取长度为 $N$ 帧的时序窗口，组合 8 路身体流的相对旋转与速度参数，形成输入特征张量 $\mathbf{X}_{\text{in}} \in \mathbb{R}^{N \times 135}$，输出配对训练样本 $(\mathbf{X}_{\text{in}}, \Delta q^*, C^*)$。
\end{enumerate}

\subsection{子系统一：多模态物理感知与硬件层详细构成}
本层负责人体运动物理信号的原始数字化采集，构成包含带不确定度的视觉辅助观测与惯性位姿两部分：
\begin{enumerate}
    \item \textbf{上半身视觉辅助参考链路}：Quest 3 / Virtual Desktop 提供身体关节估计，并通过 SteamVR 与 Feeder 链路接入服务端。实际可用 tracker、坐标变换和跟踪质量须实机确认，不假定胸部、肘部是直接测量或零漂移观测。上半身参考不能通过前向运动学自动消除各下肢 IMU 的独立偏航漂移；下肢需逐节点估计并保留已知姿态重置，详细路线见主文档第~5~节。
    \item \textbf{下半身 6 轴 IMU 阵列链路}：包含骨盆（Pelvis）、左大腿、右大腿、左小腿、右小腿及双脚踝共 6 个物理节点。每个节点硬件由 ST LSM6DSV16X 传感器与 Nordic nRF52840 SoC 构成。传感器内部运行 120\,Hz 采样与硬件抗混叠滤波，原始角速度 $\omega$ 与加速度 $\mathbf{a}$ 输入 SoC 内置的 Cortex-M4F 浮点单元，由 VQF 固件算法进行刚体旋转积分与动态加速度自适应补偿，生成无磁力计依赖的局部姿态四元数，经 2.4\,GHz ESB 私有无线协议打包发送至 PC 端的 HolyIOT USB 接收器。
\end{enumerate}

\subsection{子系统二：前置信号调理与时空对齐中继层详细构成}
由于视觉与惯性硬件来自不同物理通道，本层在 PC 服务端内存中执行传感器级信号预处理与多模态时间戳校准：
\begin{enumerate}
    \item \textbf{STA 软组织晃动自适应滤波器}：针对绑带固定于肌肉与脂肪表面引发的高频（$15\sim30$\,Hz）微小晃动，设计二阶数字低通滤波器（截频 $12$\,Hz），滤除与骨骼解剖学规律不符的高频颤颤伪影。
    \item \textbf{动态线加速度模长校验器}：持续监测加速度模长相对于 $1.0g$ 标准重力的偏离量 $e_a = \big|\|\mathbf{a}\| - 1.0g\big|$。在跑步、踢腿或急停瞬间，当 $e_a > 0.3g$ 时，标记当前加速度计受到强非重力线加速度污染，降低其重力对准权重。
    \item \textbf{多模态时钟对齐环形缓冲池（Slerp Buffer）}：在内存中开辟深度为 50\,ms 的双端队列。由于 Quest 3 视觉数据经视频编解码存在约 20\,ms 传输时延，而 2.4\,GHz 射频传输仅需约 5\,ms，两硬件数据在 PC 到达时刻存在约 15\,ms 动态相位差。该缓冲池根据数据包硬件时间戳，对高频 IMU 姿态进行四元数球面线性插值（Slerp），将其强行重采样对齐至视觉参考帧的同一物理时间切片，消除转身运动时的骨骼剪切扭曲。
    \item \textbf{特征组装器}：将对齐后的数据映射为 8 个身体通道（头部、双手、双脚、骨盆及手部相对头部偏移），每帧拼装为 135 维规范化特征向量，维护长度为 $N=20$ 的历史滑动窗口张量 $\mathbf{X}_{\text{in}} \in \mathbb{R}^{B \times 20 \times 135}$。
\end{enumerate}

网络各微观子层的运算特征与数学参数定义如下：
\begin{enumerate}
    \item \textbf{多流解耦 MLP 嵌入模块}：配置 8 组独立的线性投影层 $\text{Linear}(d_k \to 256)$，后接 $\text{LayerNorm}$ 与 $\text{LeakyReLU}(\alpha=0.1)$，将量纲不一的异构输入投射至统一的 $256$ 维潜特征空间；
    \item \textbf{因果时序编码模块}：包含 8 组独立的单向因果 LSTM（隐藏层维度 256）。每帧隐状态 $(h_t, c_t)$ 严格基于前序时间步传递，杜绝未来帧泄露；
    \item \textbf{空间自注意力编码模块}：由 3 层标准的 Spatial Transformer 堆叠而成。每层内包含两级残差跳连（Residual Addition，记为 $\oplus$）和两级 $\text{LayerNorm}$：
    \[
    \mathbf{Z} = \text{LayerNorm}\big(\mathbf{H} \oplus \text{MultiHeadAttention}(\mathbf{H})\big), \quad
    \mathbf{Y} = \text{LayerNorm}\big(\mathbf{Z} \oplus \text{FeedForward}(\mathbf{Z})\big)
    \]
    前馈网络采用先升维后降维结构：$\text{Linear}(256 \to 1024) \to \text{GELU} \to \text{Linear}(1024 \to 256)$。
    \item \textbf{三路解耦输出头}：由 3 组独立的多层感知机组成，分别承担物理意义明确的推断任务，输出任务分离，但共享主干上的反向传播梯度会相互影响。
\end{enumerate}

    \item \textbf{ZUPT 触地与双足闭链状态机}：根据模型预测的双足触地概率 $P_L, P_R$，将运动学状态分类为四类模式并施加刚体约束：单足支撑时反向锁死足底世界坐标消除滑移；双足支撑时以双足地面为闭环参考面，均摊骨盆与双膝的高度闭环误差；双足腾空时解除约束执行开链前向运动学传递。
\end{enumerate}

\subsection{子系统五：服务集成与应用交互层详细构成}
本层负责将平滑滤波后的骨骼姿态桥接至虚拟现实客户端：
\begin{enumerate}
    \item \textbf{SlimeVR Server 骨架求解器}：接收经过仲裁融合的局部旋转四元数，结合用户佩戴校准得到的骨骼长度参数（AutoBone），装配完整的全身骨架运动学模型。
    \item \textbf{独立 OSC/VMC 转发桥}：使用 Python 编写轻量中继进程，利用 \texttt{onnxruntime} 引擎在后台运行神经网络推理，监听 SlimeVR Server 广播端口（39539），将经过物理约束校正后的最终追踪点数据通过本地 UDP 套接字（127.0.0.1:9000）转发至 VRChat。
    \item \textbf{终端应用呈现}：VRChat 识别为标准 Vive Tracker 全身追踪设备，驱动角色模型骨骼，实现端到端总时延 $< 7.5$\,ms 的动作驱动（时延与漂移改善均须实测）。
\end{enumerate}

\subsection{备选技术路线对比}
除上述主架构外，保留以下两套技术路线用于消融实验与对比分析：
\begin{itemize}
    \item \textbf{备选方案 A（因果膨胀卷积 TCN）}：将主干网中的 LSTM 替换为 Causal Dilated TCN。优势在于无循环递归计算，便于在 ONNX Runtime 中做 INT8 定点量化与算子融合，CPU 推理耗时可压至 $0.8$\,ms 以内。
    \item \textbf{备选方案 B（基于姿态流形先验的后处理去噪）}：在残差输出后级引入轻量自编码器潜空间投影。当关节旋转超出生理范围时投影回自然姿态空间；为防止流形先验对非典型动作过度抑制，需引入大残差衰减与退避机制。
\end{itemize}

\section{模型代码落地与工程验收记录（2026-10-17）}
\textbf{本节是当前代码版本的实现约定，优先于前文尚未验证的结构预算与接口假设。}代码位于 \texttt{corrector/}，使用 PyTorch 实现八路独立嵌入、八路单向 LSTM、三层空间 Transformer（FFN 为隐藏维度的四倍），对当前八个身体 token 均值池化后输出三头。完整配置隐藏维度 256，实测参数量 6,689,306；可选轻量配置隐藏维度 96，参数量 974,426。完整配置不满足前文 2M 与 8MB 预算，轻量配置保留为性能基线，不声称精度等价。

残差头改为输出 $6\times3$ 维旋转向量，每分量通过 $\tanh$ 缩放至 $8\pi/(180\sqrt{3})$，随后由指数映射生成单位四元数。因此整体角度不超过 $8^\circ$，不能直接对四元数四分量乘角度限幅。采用 wxyz、右乘残差：$q^{\rm clean}=q^{\rm raw}\otimes\Delta q$。接触头与门控头分别采用 BCE 监督；门控的语义是修正可靠性，需要独立标签。当前未加入缺少解剖标定的关节极限损失。

输入契约 v1 为头显、双手三个 17 维观测与胸、髋、双大腿、双小腿六个 14 维 IMU 观测，总计 135 维；八路切分为 $(17,28,17,17,14,14,14,14)$。它并非 HMD-Poser 原生特征定义，具体字段、坐标与单位见 \texttt{corrector/README.md}。VD 胸肘辅助观测、原始设备采集和 OSC/VMC 转换尚未接入，不能宣称完整多模态链路已经实现。

训练入口接收完成序列划分与预处理的 NPZ 张量，支持 AdamW、Cosine 调度、梯度裁剪和检查点保存；不直接处理原始 AMASS。在线推理显式传递八路隐状态，重置或重定位时清空。ONNX 导出采用固定 batch=1、单帧、FP32、opset14；FP16 与硬件加速需另行验证。

工程验收脚本验证严格因果性、整段与逐帧一致、四元数单位范数、角度限幅、残差乘法方向、门控退避、三头有限梯度、微型样本优化和检查点往返。报告见 \texttt{corrector/acceptance-report.json}。这些检查不等价于真实动作精度验收：MPJPE、偏航误差削减率、触地 F1、全链路时延与真机效果仍待独立数据和设备实验；测试用微型训练权重不得投入实际追踪。

\section{全流程执行指南}
\label{sec:execution}

\subsection{阶段一：数据准备与离线切片 (Week 1--2)}
\begin{enumerate}
    \item 下载 AMASS 子库（\texttt{CMU.tar.bz2}、\texttt{HDM05.tar.bz2}、\texttt{BMLrub.tar.bz2}）及 SMPL-H 基础模型参数文件；
    \item 配置 Python 环境并安装科学计算依赖（\texttt{torch}, \texttt{numpy}, \texttt{scipy}, \texttt{human\_body\_prior}）；
    \item 运行数据预处理脚本，指定原始动捕输入路径与目标张量存储路径，配置滑动窗口长度 $N=20$ 帧（在 60\,Hz 下对应约 333\,ms 历史时序上下文）及步长 $\text{stride}=5$ 帧，输出切片后的序列张量文件。
\end{enumerate}

\subsection{阶段二：离线多任务训练 (Week 5--6)}
\begin{enumerate}
    \item 构建综合损失函数，联合优化四元数残差、触地分类交叉熵与关节角度极限约束：
    \[
    \mathcal{L} = \text{SmoothL1}(\Delta q, \Delta q^*) + \lambda_1 \text{BCE}(P_{\text{contact}}, C^*) + \lambda_2 \mathcal{L}_{\text{joint\_limit}}
    \]
    其中设置权重超参数 $\lambda_1 = 0.5, \lambda_2 = 0.1$；
    \item 使用 AdamW 优化器（初始学习率 $10^{-3}$，Cosine 退火衰减），Batch Size 设置为 256，在消费级 GPU（如 RTX 3060/4060）上训练约 80 个 Epoch。
\end{enumerate}

\subsection{阶段三：模型导出与推理优化 (Week 6--7)}
训练收敛后，将 PyTorch 计算图导出为 ONNX 格式（算子集版本 Opset 14）。指定输入张量形状为 $(B, 20, 135)$，输出节点分别命名为姿态残差 \texttt{dq}、置信度门控 \texttt{gate} 与触地概率 \texttt{contact}，并将其权重量化转换为 FP16 半精度浮点格式，生成独立的计算图模型文件 \texttt{corrector.onnx}。

\subsection{阶段四：离线基准评测与量化验证 (Week 7)}
在离线环境中载入 \texttt{DIP-IMU} 与 AMASS 验证集，运行评测脚本计算 MPJPE 误差分布、偏航漂移恢复率与触地 F1 分数，验证指标收敛性。

\subsection{阶段五：OSC/VMC 中继联调 (Week 8)}
编写 Python 中继客户端，监听 SlimeVR Server 的 OSC 默认输出端口（39539），使用 \texttt{onnxruntime} 进行实时推理，并将校正后的骨骼四元数转发至 VRChat（端口 9000），实现与上游服务端的解耦交互。
