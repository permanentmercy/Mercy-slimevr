\begin{abstract}
本项目是一套自制的低成本全身动作捕捉系统：以 nRF52840 主控与 LSM6DSV 六轴 IMU 构建 6 个追踪节点，覆盖胸、髋、两大腿与两小腿，经 Wi-Fi 接入 SlimeVR-Server 解算骨架，最终驱动 VRChat 虚拟形象。系统的核心设计是在 PC 服务端引入一层轻量神经网络，作为“姿态先验 / 去噪器”，对多传感器姿态做联合误差纠正，弥补官方服务端仅依赖骨骼几何约束与最小二乘自动测比例（AutoBone）的不足。

由于所选 IMU 为六轴（无磁力计），偏航（yaw）只能由陀螺仪积分获得，其零偏与角随机游走会随时间累积，表现为全身缓慢转偏。对此，本设计采用“上半身辅助参考 + 下半身逐节点漂移抑制”的分层抑制架构：上半身由 Virtual Desktop Estimation 生成的虚拟追踪器提供带误差与时延的辅助姿态参考。各下肢 IMU 的独立偏航漂移不会因胸部参考而自动消失；Stay Aligned、神经网络与关节约束仅用于在适用动作下减轻漂移，目标为降低误差并延长两次偏航重置的间隔，不保证长期无漂移。

校正器采用严格因果（无未来帧）的时空主干，单次前向并行输出姿态残差、传感器置信门控与足部触地判别三个结果，并经轻量物理仲裁层（加权 SLERP + ZUPT 零速锁脚）输出。训练走“纯离线数据驱动”范式：以 AMASS 光学动捕为纯净真值，注入 LSM6DSV 量级的陀螺零偏游走与噪声构造全合成配对样本，无需真人标注，也无需等待硬件到位；泛化能力由真实物理传感器数据集 DIP-IMU 独立评估。目标指标为单帧推理 $\le 2.0$\,ms（GPU FP16）、平均关节位置误差 MPJPE $\le 45$\,mm、偏航误差削减率（待验证） $\ge 88\%$、足部触地判别 F1 $\ge 93\%$。端到端管线延迟控制在 20\,ms 以内。
\end{abstract}

% ==================== 1 项目概述 ====================
\section{项目概述}
\label{sec:overview}

本项目基于 SlimeVR 开源方案，自制一套以 nRF52840 + LSM6DSV 为核心的 6 点全身动作捕捉系统，用于 VRChat 虚拟形象驱动；核心设计是在 PC 服务端引入轻量神经网络，对多传感器姿态做联合误差纠正。

\textbf{动机。}商用全身追踪方案价格高昂，而 SlimeVR 开源硬件可将整套成本压到千元以内，显著降低虚拟形象驱动的门槛。

\textbf{创新点。}SlimeVR 官方服务端仅依赖骨骼几何约束、最小二乘自动测比例（AutoBone）与脚锁做纠偏：各 tracker 的姿态估计由固件侧 VQF 融合给出，服务端信任该朝向并装配成骨架，现有 Stay Aligned 可借助放松姿态先验逐步减轻偏航漂移，但不能保证任意动作下均可恢复真实航向。本设计在服务端增加一层神经网络姿态先验，用于抑制抖动、穿模与偏航漂移。

% ==================== 2 总体架构 ====================
\section{系统总体架构}
\label{sec:arch}

% ==================== 3 硬件设计 ====================
\section{硬件设计}
\label{sec:hw}

6 个 tracker 分布于胸、髋、两大腿与两小腿，全部采用 6 轴 LSM6DSV（三轴加速度计 + 三轴陀螺仪，无磁力计），主控为 nRF52840，运行基于 Zephyr / nRF Connect SDK 的固件，经 Wi-Fi 将姿态数据回传至 PC 端 SlimeVR-Server。

每个追踪节点由 nRF52840 主控板、LSM6DSV IMU、电池与外壳构成；整套系统另需一个无线接收器用于汇聚 6 路数据，以及 DAPLink 调试器用于烧录与救砖（见第~\ref{sec:firmware} 节）。

% ==================== 4 固件与工具链 ====================
\section{固件与工具链}
\label{sec:firmware}

固件基于 nRF Connect SDK（Zephyr）构建，追踪器与接收器需使用\emph{不同}的 NCS 版本，因此各自建立独立的 west 工作区。该环节的主要风险与对策如下：

\begin{itemize}
    \item \textbf{IMU 识别待实机验证}：本项目所用器件在固件器件表中以 \textbf{LSM6DSV} 登记（I2C 地址 \texttt{0x70}），因此本文档全文统一称其为 LSM6DSV。但具体批次实际回报的器件 ID 仍需实机确认（已设为闸门 G1）：需通过实机 \texttt{info} 输出核对，若回报 \texttt{0x71} 则会落到 ISM330BX 驱动分支，需另行评估。
    \item \textbf{编译环境庞大}：NCS 工具链体积大，且追踪器与接收器版本不同，环境搭建易出错，需固定 commit 并单独记录。
    \item \textbf{刷写风险}：焊接与烧录顺序错误可能导致设备变砖；已准备 DAPLink 作为救砖手段。
    \item \textbf{算力边界}：nRF52840 无 NPU、算力不足，神经网络模型不应下沉到设备端，推理统一放在 PC 侧。
\end{itemize}

% ==================== 5 漂移与分层抑制 ====================
\section{偏航漂移问题与分层抑制架构}
\label{sec:drift}

\subsection{漂移机理}
\label{subsec:drift-mech}

本项目全部采用 6 轴 IMU（加速度计 + 陀螺仪，无磁力计），因此无法获得绝对偏航参考：加速度计只能依靠重力校正俯仰（pitch）与横滚（roll），而偏航（绕重力轴的旋转）只能由陀螺仪积分得到。各节点的陀螺零偏与角随机游走独立累积，可能导致不同肢段分别转偏；漂移速度受器件、温度、标定与运动影响，应由实机测量，不能以固定数值代表本系统。为此本设计引入“上半身辅助参考 + 下半身逐节点漂移抑制”的分层抑制架构。

\subsection{组件与数据流}

上半身姿态（胸 / 肩 / 肘 / 腕）由 Virtual Desktop 的 Estimation 功能提供：它利用 Quest 3 头显自带的下视侧摄做 Inside-Out Body Tracking（IOBT），生成一组“虚拟 tracker”，其身体关节位姿是视觉与人体模型共同估计的结果，可能受遮挡、估计误差、时延及参考空间重定位影响，不应视为零误差或零漂移的直接测量；在已有兼容头显的前提下可不增加身体追踪硬件。VD 虚拟 tracker 在 SteamVR 中以设备形式暴露，经由官方 SlimeVR Feeder App（随 SlimeVR 安装器附带、随 SteamVR 启动的 OpenVR 桥）通过命名管道喂入 SlimeVR-Server，与本项目的 6 个 IMU 在同一套骨架求解器中统一解算。社区工具 Virtual Desktop Body Tracking Configurator 可关闭 VD 的下半身虚拟 tracker（Generative Legs），仅保留上半身，把腿留给 IMU。

官方兼容文档明确 SlimeVR 与 Virtual Desktop Estimation “specifically for arms” 搭配使用（\url{https://docs.slimevr.dev/misc/compatibility.html}）。这说明存在上半身融合使用路径，不构成胸部或肘部准确度、可用性与下肢漂移消除的保证。具体设备输出与优先级须实机确认。

\subsection{漂移抑制分层}

\begin{itemize}
    \item \textbf{第一层（参考空间与上半身辅助观测）}：将 HMD 与可用的 VD 上半身位姿变换到统一坐标系，依据跟踪状态、时延和创新残差分配权重。胸部观测只约束被观测肢段；前向运动学传播位置，不会自动校正大腿、小腿 tracker 的独立偏航误差。
    \item \textbf{第二层（下半身逐节点估计）}：为髋、大腿与小腿分别维护偏航修正及其不确定度，结合 Stay Aligned、膝关节近似铰链约束和可靠接触事件，条件性地约束相对朝向。局部漂移不保证比上半身漂移小；髋关节自由度高、伸腿静止等退化姿态下约束可能不足。
    \item \textbf{第三层（学习先验与失效恢复）}：神经网络提供小幅残差与候选权重，在分布外动作或低可观测状态下减弱更新。不能把真实转腿与漂移始终区分开；持续异常时提示用户执行已知姿态的偏航重置，或使用外部下肢观测重新锚定。
\end{itemize}

\subsection{可实施的下肢漂移抑制路线与边界}
\label{subsec:heading_solution}
推荐先建立规则与运动学基线，再接入学习模块。以下均为待实现、待验证的设计，不代表现有旁路已经具备这些能力。
\begin{enumerate}
    \item \textbf{源头减漂}：先验证固件静止零偏估计与标定效果，记录预热、温度变化和不同动作下各 tracker 的漂移；固定绑带并检查安装标定，区分安装滑动与陀螺漂移。静止零角速度更新可估计零偏，但不能恢复已经丢失的绝对偏航。
    \item \textbf{持续状态估计}：设 $\hat q_i = R_g(\delta\psi_i)\otimes q_i^{\rm raw}$，其中 $R_g$ 是绕世界重力轴的旋转，为每个节点维护 $\delta\psi_i$；具备原始角速度时可进一步估计陀螺零偏。采用误差状态滤波或小规模约束优化，限制更新速率、记录不确定度，并与固件已有零偏补偿明确分工。
    \item \textbf{条件性运动学约束}：在完成传感器到肢段标定后，以屈伸时膝关节近似铰链轴的一致性约束大腿与小腿的相对偏航。应检测运动激励与约束残差；退化动作下冻结或减弱相关更新。真实膝关节并非理想铰链，髋关节也不能强行套用该约束。参考可观测性研究：\url{https://arxiv.org/abs/2102.02675}。
    \item \textbf{接触与视觉辅助}：可靠支撑相中以软约束抑制足端速度与高度误差，允许足部转动、脚跟抬起和接触切换。当前没有足部 IMU，不能直接把小腿静止等同于足底静止；触地约束也不是绝对航向观测。VD 仅在跟踪有效、坐标对齐且时延可控时约束上半身，不将胸部 yaw 直接复制给髋或双腿。
    \item \textbf{学习与恢复}：神经网络优先预测接触、异常和小幅姿态残差，权重还需结合规则检查与独立验证；不能仅凭网络自报置信度保证安全。持续不可观测时保留用户确认的已知姿态重置。若目标是长时间强约束下肢航向，应增加可见的腿部视觉标记或外部位置/姿态追踪；单个胸部或骨盆参考仍不足以保证所有下肢节点可观测。
\end{enumerate}
验收以原生 SlimeVR（含 Stay Aligned 与脚锁）为基线，分别比较源头标定、运动学约束及神经网络的增益。按站立、走动、转身、坐姿、盘腿与躺卧分别记录偏航误差、误修正率、脚滑距离和达到预定误差阈值前的重置间隔；没有独立真值时不得将自洽骨架误差称为真实跟踪精度。

\subsection{Stay Aligned 与神经网络校正器的互补}

Stay Aligned 是规则式姿态先验：每 tick 将 tracker 偏航朝“校准时的放松姿态”做梯度下降微调，它读取的是玩家自身姿态与放松姿态先验，\textbf{不读取头显偏航}，因此本身并非绝对参考；其盲区在于非放松姿态（侧躺、大幅跳舞、前倾）时放松姿态不成立而失效。

神经网络残差校正器从 AMASS 等大规模动捕数据中学到“人类在各活动下的合理姿态分布”，有机会改善部分训练覆盖的非放松动作，但不能保证覆盖上述盲区或恢复不可观测的真实偏航。二者同属姿态先验类，神经网络是 Stay Aligned 的\emph{补强}而非替代；代价是神经网络可能产生“幻觉”（将姿态掰到合理但错误的位置），因此必须采用残差叠加 + 置信门控的形式（见~\ref{subsec:discipline}）。

% ==================== 6 神经网络残差校正器 ====================
\section{服务器端神经网络残差校正器}
\label{sec:nn}

\subsection{问题定位}

SlimeVR 官方服务端仅用骨骼几何约束、最小二乘自动测比例（AutoBone）与脚锁做纠偏，各 tracker 的姿态估计由固件侧 VQF 融合给出，服务端信任该朝向并装配成骨架。其局限是：Stay Aligned 等现有约束依赖动作与先验适用性，无法保证任意动作下的真实偏航可观测。

此外，纯开链几何解算缺少足部触地约束，静止站立时下肢易出现“滑步 / 溜冰”现象。因此本设计在 PC 服务端增加一层轻量神经网络，作为“姿态先验 / 去噪器”，同时输出姿态残差、传感器置信门控与足部触地判别，对多传感器姿态做联合误差纠正。

\subsection{输入与输出}

\textbf{输入：}滑动窗口特征 $\mathbf{X}_{\text{in}} \in \mathbb{R}^{N \times 135}$，由两路构成——(a) 上半身辅助参考：Quest 3 / VD Estimation 提供的胸、手肘估计位姿及其可用性标记（带误差与时延）；(b) 下半身 6 点 LSM6DSV 的角速度与加速度。两路数据先经时间戳 Slerp 环形插值缓冲池（50\,ms）对齐，以消除视觉传输（$\sim$20\,ms）与 2.4G 射频（$\sim$5\,ms）之间的相位差。

\textbf{输出（多任务头，单次前向并行给出）：}
\begin{itemize}
    \item \textbf{姿态残差头} $\Delta q$：各下半身关节的局部四元数残差，单帧角度限幅 $\le 8^{\circ}$；
    \item \textbf{可靠性门控头} $W$：传感器置信度，低置信时退避回原值；
    \item \textbf{触地判别头} $C$：左右脚触地概率 $P_L, P_R \in [0,1]$，供零速修正（ZUPT）与锁脚使用。
\end{itemize}

最终装配由轻量物理与运动学仲裁层完成：按置信度做加权 SLERP 叠加，并在双足同时触地时进行闭链支撑仲裁，避免单脚浮空或陷入地面。

\subsection{网络结构}

主干采用\textbf{因果时空网络}：8 路独立\emph{单向因果} LSTM（$256$ 维，严格不引入未来帧，保证在线推理零额外时延）+ Spatial Transformer 编码器（跨关节解剖关联注意力）。在此之上并列三个多任务头（残差 $\Delta q$ / 门控 $W$ / 触地 $C$），单次前向完成全部解算，避免运行时级联多个异构模型。

\subsection{训练数据与目标函数}

训练与验证全部离线完成，不依赖硬件进度。

\textbf{训练集（AMASS）}：以 MPI 发布的 AMASS 光学动捕为纯净真值（SMPL-H 关节旋转矩阵与全局平移）。精选三个子集即可覆盖日常动作，总量约 2.9\,GB，无需下载全量：\texttt{CMU}（约 1.5\,GB，走 / 跑 / 坐 / 转身 / 下蹲 / 跳跃）、\texttt{HDM05}（约 800\,MB，规范化高精度步态）、\texttt{BMLrub}（约 600\,MB，连续步态循环与原地踏步，是触地检测的最佳样本）。正向运动学计算需预先获取 SMPL-H 人体模型参数包。

\textbf{评估集（DIP-IMU）}：MPI 开源的 DIP-IMU（约 1.5\,GB）记录了 10 名被试佩戴 17 颗 Xsens 工业级 IMU 时的 Vicon 光学真值，可在硬件完成前就用\emph{真实}物理传感器数据检验模型对温漂、抖动与软组织晃动的泛化能力。

\textbf{合成加噪}：对每个下半身关节注入偏航随机游走
\[
\psi_t = \psi_{t-1} + b_{\text{gyro}}\Delta t + \sigma_{\text{arw}}\sqrt{\Delta t}\,\epsilon_t,\qquad \epsilon_t \sim \mathcal{N}(0,1)
\]
并叠加加速度扰动与高斯白噪声；同时由脚踝速度与离地高度生成触地真值（$v_{\text{foot}} < 0.1$\,m/s 且 $z_{\text{foot}} < 0.03$\,m 时置 1）。监督目标为残差 $\Delta q^{*} = (q^{\text{corrupt}})^{-1} \otimes q^{*}$，构成 corrupted→clean 配对，无需真人标注。

\textbf{损失与优化}：
\[
\mathcal{L} = \text{SmoothL1}(\Delta q, \Delta q^{*}) + \lambda_1\,\text{BCE}(P_{\text{contact}}, C^{*}) + \lambda_2\,\mathcal{L}_{\text{joint\_limit}}
\]
取 $\lambda_1 = 0.5$、$\lambda_2 = 0.1$；使用 AdamW 优化器（初始学习率 $10^{-3}$，Cosine 退火衰减），Batch Size 为 256，在消费级 GPU 上训练约 80 个 Epoch。

\subsection{与 SlimeVR 的集成方式}

\textbf{松耦合（推荐）：}SlimeVR 经 OSC / VMC 输出骨架 → 独立神经网络进程消费 → 清洗后回写 OSC / VMC 给 VRChat，不改动 SlimeVR 代码。工程上实现为一个轻量 Python 中继客户端：监听 SlimeVR Server 的 OSC 广播端口（6969 / 39539），用 ONNX Runtime 做实时推理，再将滤波与锁脚后的骨骼四元数重定向发送至 VRChat（端口 9000），即插即用、非侵入。

\textbf{紧耦合：}fork SlimeVR Server，在骨架计算后插入推理；需经 JNI / 子进程 / ONNX Runtime 桥接 Java 与模型。

\subsection{延迟与部署约束}

VR 要求端到端管线 $\le 20$\,ms（从 IMU 打包到 VRChat 收到骨骼）。其中神经网络单帧前向推理预算为 $\le 2.0$\,ms（GPU FP16），CPU 上的 ONNX 路径放宽至 $\le 4.5$\,ms；轻量物理与运动学仲裁层耗时控制在 $0.3$\,ms 以内。训练收敛后导出为静态计算图（ONNX，opset 14）并转换为 FP16，由 ONNX Runtime / TensorRT 执行。

部署边界明确：nRF52840 无 NPU、算力不足，模型\textbf{不}下沉到设备端，推理统一在 PC 侧完成。

\subsection{实现纪律与评测}
\label{subsec:discipline}

为使神经网络稳妥，须遵守以下纪律：(1) 仅输出小幅度残差四元数 $\Delta q$ 并叠加回原朝向，绝不整体替换骨架；(2) 加置信门控，低置信时不修正、退回原值；(3) 训练数据全合成——以 AMASS 干净全身骨架为监督，经简化前向运动学重建后，在下半身关节注入 LSM6DSV 量级的偏航随机游走漂移（陀螺零偏 / 角随机游走）与 IMU 噪声，构造 corrupted→clean 配对回归残差，无需真人标注；(4) 结构以因果（单向）LSTM 主干起步，备选 A 的因果膨胀 TCN 用于消融对比；(5) 评测先量化后上线——在合成漂移上测均方误差与偏航误差恢复率（如注入 $10^{\circ}$/min 漂，看网络收敛回多少），达标后再上真机对比 reset 频率、穿模率与滑步距离；(6) 残差输出必须限幅（单帧角度 $\le 8^{\circ}$），并在出现异常大残差时自动退避，防止模型把姿态掰到“合理但错误”的位置。整体评测不依赖“感觉更稳”的主观判断。
