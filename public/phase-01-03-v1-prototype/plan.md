# Phase 1–3：v1 原型、训练与 ONNX 工程基线

> **状态**：已完成，作为算法与部署工程基线。  
> **范围**：AMASS 数据流水线、因果时空模型、多任务训练、数学验收、流式 ONNX 导出。

## 子计划

1. 建立 SMPL-H / AMASS 数据获取、整理与训练切片流水线。
2. 实现紧凑 CSTN 时序模型与姿态残差、门控、足底接触输出。
3. 验证旋转数学、因果性、序列/流式等价性、检查点读写和训练数值稳定性。
4. 导出流式 ONNX，记录单线程 CPU 推理、模型体积和 PyTorch/ONNX 对齐误差。

## 验收边界

- 工程数学检查和模型导出通过。
- 合成残差拟合与合成接触分类只作为训练管线指标。
- 不以 v1 合成分数宣称实机偏航漂移已得到改善。
