5. 回放和实机验证通过后，再实现受配置控制的修正写入与超时旁路。

- Kotlin 输入向量与 Python `contract_v2.py` 逐维一致，使用固定姿态/角速度样例交叉验证。

- 影子模式不修改 tracker/Avatar；在线模式的修正能在正确位置应用，reset 会清空模型状态。
