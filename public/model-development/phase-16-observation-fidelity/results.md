## P16.0：服务端输入来源审计

### 核实事实

1. [`CorrectorBridge.kt`](../../../server/server/core/src/main/java/dev/slimevr/tracking/processor/corrector/CorrectorBridge.kt) 中下肢 14D 观测流包含：姿态 6D、加速度计向量 (3D)、角速度 (3D)、valid 标志和数据 age。若 `Tracker.getAngularVelocity()` 为空，服务端通过相邻融合四元数差分调用 `computeAngularVelocity()` 计算因果角速度。
2. [`Tracker.kt`](../../../server/server/core/src/main/java/dev/slimevr/tracking/trackers/Tracker.kt) 中角速度缺省为 `Vector3.NULL`，当前仓库无任何生产路径调用 `setAngularVelocity()`，因此进入 CorrectorBridge 的角速度走的是姿态差分路径。
3. [`bias_estimator_v3.py`](../../../ai_corrector/corrector/bias_estimator_v3.py) 原先配置了 `accel_var_thresh`，但 `StationaryZARUDetector.update()` 实际上未接收加速度数据，仅依赖角速度模长门限（$0.08\text{ rad/s} \approx 4.6^\circ/\text{s}$）。这意味着如果人体以小于 $4.6^\circ/\text{s}$ 的极慢速度挪动肢体，原版检测器会将其误判为静止漂移并执行反向补偿。

## P16.2：动力学自洽四元数积分物理合成器

为废除原先相互割裂的独立姿态与陀螺生成，开发了 [`physics_session_simulator_v4.py`](../../../ai_corrector/corrector/physics_session_simulator_v4.py)：
1. **严格四元数动力学积分**：$\dot{q} = \frac{1}{2} q \otimes \boldsymbol{\omega}$，以 $100\%$ 的物理与数学自洽性耦合姿态演化与传感器角速度读数；
2. **机体轴物理加速度计模型**：$\mathbf{a}_{\text{meas}} = R(t)^T (\mathbf{a}_{\text{motion}}(t) + [0, 9.81, 0]^T) + \mathbf{n}_{\text{acc}}$。利用人体肢体自主运动必伴随肌肉颤动（Muscle Tremor, $\sim 8\text{–}12\text{ Hz}$）与重力投影倾角微变的物理本质，为 ZARU 提供加速度方差作为第二独立判据；
3. **真实极慢动作切片**：构建人体 $0.3^\circ/\text{min}$ 极慢自主转腿工况，伴随微弱肌肉颤动（$\text{Var}(\mathbf{a}) > 0.05$），用于严格考核观测器的误校正防御边界。

## P16.4：架构裁定与生产结论

基于 P16.0–P16.3 的源码审计与物理自洽基准实验，做出以下决定：

1. **废弃仅依赖角速度阈值的朴素 ZARU 观测器**：
   - 实验明确证实：无论角速度来自原始陀螺仪还是服务端姿态差分，当人体主动以慢于角速度门限（$<0.08\text{ rad/s}$）挪动下肢时，朴素 ZARU 会产生高达 **4,768 次误更新**，强行将人体姿态反向纠正 **11.97°**，导致胜率跌至 **0.0%**。
   - 证明单纯切换角速度计算来源（使用 `computeAngularVelocity`）无法解决误校正问题。
2. **正式采纳 Phase 16 保守型三态观测器 (`ConservativeBiasEstimatorV4`) 作为慢分支基准架构**：
   - **加速度微方差门控**（$\text{Var}(\mathbf{a}) < 0.04\text{ (m/s}^2)^2$）：利用肌肉颤动与重力倾角变化的物理特征，将真实自主慢动作彻底阻断在静止状态之外（误更新彻底清零至 0 次）。
   - **多 Tracker / HMD 相对运动学一致性**：在上身转身时全局挂起下肢 ZARU 更新，防止全身慢转被切片误判。
   - **明确三态逻辑**：在物理证据不足时输出 `UNCERTAIN`（仅膨胀协方差 $P \leftarrow P + Q \cdot dt$，拒绝移动估计偏航 $\hat{e}$），恪守“缺乏独立物理证据时，拒绝更新优先于回正”的设计铁律。
   - **单腿隔离有效性**：在单腿动、单腿静的复杂混合工况中，将朴素 ZARU 的负增益（$-0.71^\circ$）逆转为显著正增益（$+2.39^\circ$，胜率 100%）。
3. **保持 0 参数扩容与冻结快分支**：
   - 慢分支为显式状态滤波算法，新增 0 个神经网络参数；
   - 系统总参数量保持在 **1,102,066**，与 Phase 15 完全一致。
4. **安全边界与实机路径**：
   - 当前在 SlimeVR Kotlin 服务端代码库中保持 `shadowMode = true` 与 `enabled = false`；
   - 仿真合成评测仅用于验证观测器动力学与算法边界，严禁将合成结果夸大为硬件实测结论；
   - 待硬件到货后的实体传感器长时温漂与真实人体佩戴长会话，归入 **Phase 8** 硬件联调阶段。
