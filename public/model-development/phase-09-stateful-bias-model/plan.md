# Phase 9：四路下肢偏航状态模型重构

> **状态（2026-10-18 审计后）**：M0 几何单测通过；M1r/M1r-F 在 10 条 30 分钟合成会话报告 Full 均值改善 96.6%，可作为研究信号，不能视为实机验收。主报告的零漂安全状态只检查 ZARU；Full 在两条标称 0°/min 会话中仍显著改变终点姿态，压力测试零漂档还含随机游走。因此 Full 零漂安全未通过证明，M2/在线应用暂不开放。Phase 6/9 的互补组合路线见 [Phase 11 计划](../phase-11-hybrid-compensation/plan.md)，详见 [执行记录](results.md)。
> **唯一主目标（2026-10-17 修订）**：一次 reset/标定后连续运行至少 **30 分钟**，比较开始与结束时四颗腿部 IMU 的**累计偏航误差增长总量**；修正后的终点增长总量要小于原始 SlimeVR 输出。短窗精度、全程逐帧平均误差和短时动作姿态不是主目标。
> **目标场景**：左/右大腿、左/右小腿各一颗 IMU；HMD 和可缺省 VD 上身虚拟追踪器提供带质量标记的运动上下文。不能假设上身方向自动校正腿部。

## 架构决策

**不继续扩容现有“20 帧输入 → 每帧 3D 四元数残差 + gate”作为主线。** 当前 `train.py` 打乱窗口且每窗清零 LSTM 状态；即使 `model.py` 有状态接口，训练目标也没有显式偏航误差或漂移率。20 帧在 60 Hz 只有 0.33 秒；现有最长约 5 秒源动作也无法承载至少 30 分钟的终点目标。加长单次原始帧窗口不是解决办法。

采用**四路独立慢偏移状态 + 稀疏锚点更新**。每颗传感器 `i` 的显式状态为世界竖直轴偏航误差 `e_i`、其变化率 `b_i`，以及二者的 `2×2` 协方差 `P_i`；安装偏差 `M_i` 属于标定参数。每帧按真实时间戳预测 `e_i ← e_i + b_i·Δt`。网络寻找可以和会话开始或先前可靠锚点比较的重复姿态/步态片段、关节几何关系及上身参考，输出对**累计偏移量**的候选测量与不确定度。只在可靠锚点更新状态；其余时间维持预测。模型不需要判断某个短时间动作是否偏离“正确动作”，也不输出任意逐帧 3D 旋转残差。

在线计算分两部分：

1. **事件编码器（秒级片段，仅为寻找可比锚点）**识别站立/标定姿态、重复步态相位、转身、腿段相对旋转及 HMD/VD 质量；记录起始与后续可信事件的特征摘要和时间戳。它不接受“短期姿态越接近先验越好”的逐帧目标；没有足部传感器时，推断接触只作为概率线索，不能把脚支撑当成腿段静止。
2. **慢分支（至少 30 分钟、常量或有界大小的状态）**存储四路 `e_i,b_i,P_i` 和少量会话锚点/GRU 摘要，按时间连续推进。锚点匹配可能相隔数分钟，更新频率由证据决定，不能固定假设每 0.1–0.2 秒都有有效观测。推理内存与单帧计算量不随会话长度线性增长；不对 30 分钟原始帧做全注意力。

观测网络必须给出逐颗传感器的**有符号累计偏移候选值**（或 innovation）和方差，而不只给接触概率。在线锚点来自初始 reset 后保存的可部署特征，以及会话中自动识别、在几何和运动上下文上确实可比的事件；不能仅因两段动作标签相同就强行对齐朝向。**独立光学/其他真值只用于训练监督和离线验收，绝不作为在线模型输入**。膝关节约束、左右步态和 HMD/VD 参考均作为有噪声证据并通过消融验证。正负漂移反事实配对用于防止网络只记动作类别。若长时间没有可信锚点，方差应增大、输出应保守，并在报告中记录该会话缺少有效校正证据。

### 主验收指标：会话终点累计误差

对每次独立的 ≥30 分钟会话，以同一独立姿态真值计算每颗传感器在开始 `t0` 和结束 `t1` 的世界偏航误差 `e_i(t)`。为降低单帧抖动，在 `t0/t1` 附近预先固定的短区间取稳健中心值；**只在这两个端点取值**，不对整个会话逐帧平均。定义 `D_raw = Σ_i |wrap(e_raw,i(t1) − e_raw,i(t0))|`，`D_corr` 用相同公式计算修正后误差。主收益 `G = D_raw − D_corr`，改善率 `G / D_raw`；若 `D_raw` 接近零，只报告绝对变化，避免比例失真。四路等权，总误差不得用有符号偏差相互抵消。另报每路 `|Δe_i|`、最大恶化、会话胜率与按会话 bootstrap 的置信区间。终点参考必须独立于模型输出；若使用固定标定动作，应在开始/结束复现相同定义并记录实际真值。

### 旋转与在线输出契约

在统一的世界参考系中，若已标定的原始腿段旋转满足 `R_raw = R_y(e_i) R_clean`，则 `R_corr = R_y(-e_hat_i) R_raw`。如果尚含安装矩阵，先在独立标定流程定义并消去 `M_i`，不可把安装误差并入漂移学习。旧桥接若仍要求右乘 `R_raw @ R_dq`，应转换为 `R_dq = R_rawᵀ R_y(-e_hat_i) R_raw`；四路分别转换，并用随机三维姿态、正负偏移和不同安装矩阵做独立 oracle 测试。明确 SlimeVR、数据集和 ONNX 的坐标轴、四元数分量次序与乘法方向。输出同时记录 `e_hat_i,b_hat_i,P_i` 与应用/旁路原因，便于影子回放。

### M1r：修复可部署输入与终点对照（合成原型已执行；安全验收未通过）

1. **先重建数据边界。** 从真实同步的四路腿部 IMU + HMD/VD 长会话获得可部署输入；若先做仿真，须输出完整连续的干净/原始腿段运动姿态、上身流、缺测和可比较事件，输入生成函数不得读取 `true_drift_angles`、真值旋转、合成漂移率或未来会话总时长。真值只进入标签和离线指标。静态审计/运行时断言检查这一隔离；保存可回放会话与新 manifest/哈希，旧 M1 Test 改称开发集。
2. **修正角度与数据范围。** 明确终点姿态误差采用圆周 `wrap` 后的角度；若还要报告超过 180° 的累计转数，额外记录展开角，不能与终点姿态误差混用。将监督改为圆周创新量/损失，或显式分离展开转数状态。仿真漂移率先依据实机统计定标，单列低漂移和零漂移会话；禁止仅用 ±15°/min 推断 SlimeVR 的真实 30 分钟工况。
3. **重新训练并做有效对照。** 锚点必须由可部署流中的事件检测器产生，不能由固定的每 3 分钟索引或独立端点真值提供。真实运行旧 CSTN 权重才可列入模型对照，否则删除该列。选模使用会话终点 `G` 和无损伤条件，不用 NLL 单指标；保留 Raw、已知真值 oracle、可部署锚点、锚点+滤波等层次，并在每会话/每路报告结果。
4. **修正机器状态与验收。** `PASS` 必须由实际成功条件计算，`G≤0` 或置信区间不支持正收益时为 FAIL/探索性；禁止固定布尔结论。先在新的隔离仿真会话做因果回放，再在 ≥30 分钟且起终点有独立真值的实机会话上评估。实机数据未取得前，M2 保持未验收。

#### M1r-F：指定频域辅助方案与前置条件

**决策**：优先做逐颗传感器的 **ZARU/静止段陀螺零偏估计**，用频谱/窗口能量只判断何时允许更新；在可信的直线前进步态中，再试摆动轴 + HMD 位移方向作为低权重偏航观测。拒绝“腿朝向向 HMD 平均朝向以 15–20 分钟时间常数缓慢回归”的默认策略。频域本身不提供绝对偏航：角速度 `ω_meas = ω_motion + b_gyro + noise` 中，零偏位于低频，但真实持续转身、静坐姿态也含低频/直流；对姿态角做高通或低通会误改正常动作。

1. **先审计真实数据接口，不满足就停止此方案的实机主线实施。** [`contract_v2.py`](../../../ai_corrector/corrector/contract_v2.py) 是前四路视觉各 17 维、后四路 IMU 各 14 维；[`contract_v3.py`](../../../ai_corrector/corrector/contract_v3.py) 的 `V2ToV3Adapter` 已修正为这一布局，映射测试代码已提供。它不验证实际硬件来源。旧合成 `ang_vel` 由姿态差分得来，**不能当作传感器裸陀螺读数**。仓库协议定义了可选 `rawAngularVelocity`，但需在具体四颗设备的固件、传输、服务端和录制链路逐层验证其实际提供频率、单位与坐标轴；只拿到融合后的旋转时，先做姿态静止段残余漂移率的受限实验，不宣称已估计硬件陀螺零偏。
2. **主分支：每颗 IMU 独立静止门禁与零偏状态。** 从该颗传感器的原始角速度和加速度计算短时 RMS/方差、频带能量、`|a|-g`、观测持续时长；门限由设备静止标定噪声和验证集设定，不预设 `2–15 Hz` 小波能量为“绝对静止”。候选连续数秒且原始角速度接近当前偏置估计时，稳健平均 `ω_meas` 更新该颗 IMU 的**传感器坐标系三轴陀螺零偏**及方差；随后在姿态融合前扣除零偏、重积分或走经验证的 AHRS 前端。若只改服务端已融合的旋转，必须单独证明静止段姿态斜率与未来偏航漂移的关系。脚触地不能触发大腿/小腿的零角速度更新；只检查该颗 IMU 是否静止。坐着、侧坐、翘腿静止可更新零偏，但不改变当下静态姿态角。
3. **辅助分支：可信直线步态才测摆动面。** 对去零偏后的腿部角速度做随步频自适应的带通与多步 PCA/周期一致性检测，得到摆动轴**无符号轴线**；用重力方向与相位信息处理轴线的 180° 歧义。仅在 HMD 连续位移足够、轨迹近直线、明确向前步行、左右步态一致、VD/HMD 质量合格时，把多步平均 HMD **位移方向**与已校准的腿部摆动面比较，产生逐路偏航候选及较大观测方差。原地踏步、转圈、侧移、倒走、低位移和不对称步态一律拒绝；HMD 头朝向不能代替位移方向。摆动轴首先用于传感器到腿段对齐/相对几何检查，能否提供可用世界偏航观测要由独立真值消融决定。
4. **消融与验收。** 同一组 ≥30 分钟原始传感器日志比较 Raw、仅静止零偏更新、仅步态辅助、二者融合及真值 oracle；逐会话报告端点 `D_raw/D_corr/G`、四路单项和校正事件次数。单列“全程侧坐静止”“正常前进/转身/侧移/倒走混合”“无可信静止段”“VD 缺失”会话，检验假锚点和漏锚点。选频段、门限和置信度只看训练/验证会话；隔离实机集按 M2 终点规则一次验收。若裸陀螺无法获取或两分支在真实端点无正收益，明确记录输入瓶颈，不以长时间常数的姿态回正替代证据。

#### M1r 复核后的压力测试（脚本已运行；通过结论撤销）

1. **零漂安全没有按“直通”标准验证。** [`session_simulator_v3.py`](../../../ai_corrector/corrector/session_simulator_v3.py) 即使 `drift_tier=0` 仍对每路累加随机游走 `rw`，所以压力报告的 `zero_drift_safe` 不是零硬件漂移金标。压力脚本只要求 `D_corr <= D_raw + 8°`；报告的 `4.87° <= 5.49°` 说明误差增加低于宽松阈值，不代表直通或零损伤。该场景中 ZARU only 为 `5.84°`，比 raw `5.49°` 更差，Full 依赖步态支路降到 `4.87°`。
2. **“动态死区”与实现不符。** 报告称 $1.5°/min + 3σ$ 门禁；[`bias_estimator_v3.py`](../../../ai_corrector/corrector/bias_estimator_v3.py) 实际使用固定 `1.5°/min` 下限和 `2.5×stderr`，没有三轴陀螺偏置校准；所用 `ang_acc` 全零且没有参与 `is_still` 条件。该接口字段为角加速度，也不能替代线加速度静止判定。
3. **步态检测只证明脚本产生了候选。** X-Z 投影修正有效消除了原来的坐标切片错误；但当前检测器未计算轨迹直线度、步频/相位一致性，也未实现多步 PCA 摆动面。复合步态场景中 gait-only 退化 `13.91°`，Full 的收益不能单独归因于步态分支有效；零漂场景触发 `10,822` 次步态事件，可能误把合成随机游走/姿态变化当作偏移证据。
4. **压力集结果仅供开发诊断。** `all_sitting`、`no_still`、`vd_missing`、`complex_gait` 五组报告可复现地记录在 [`m1r_ablation_stress_report.json`](../../../ai_corrector/artifacts/m1r_ablation_stress_report.json)，但只有一个 seed/场景，非独立验收集。即使报告机器状态为 `PASS`，也不能推进 M2 或实机姿态应用。`ang_vel` 的实际采样链路被源码审计为标准 UDP tracker data 未保证提供裸陀螺；当前算法须按计划降格为融合姿态/角速度流上的残余漂移估计，不宣称硬件 ZARU。

**当前判定：执行脚本完成；物理有效性、零漂安全和步态收益均未通过验收。** 后续先构造零漂严格为零且可控随机游走单独分层的对照，再冻结无损伤阈值，修正信号物理模型和步态条件；只有隔离会话结果满足 M2 门槛，才推进实机影子评估。

### M2：可用性验收与接入

1. 在**从未用于调参的 ≥30 分钟实机会话**上按冻结口径计算每会话 `D_raw/D_corr/G`；45、60 分钟及更长会话单独分层。主表逐会话列出四路开始/结束误差增长与总量，汇总会话胜率、`G` 的中位数及配对置信区间，另报最差会话、最大单路恶化、VD 在线/缺失和设备变化。合成 0/1/3/10°/min、逐帧偏航/FK/足滑、检测延迟仅作诊断/安全指标，不与主目标混成一个平均分。
2. **成功判定**：在隔离的 ≥30 分钟会话上，终点总增长 `D_corr < D_raw`，且跨会话配对 `G` 的置信区间下界大于 0；报告所有失败会话和四路单项，不能靠某一路巨大改善掩盖另一颗显著恶化。若原始漂移本来近零，模型应接近直通。姿态突跳、丢包/reset 后异常及不可接受的单路恶化作为独立安全否决项；其具体阈值在验证集冻结后再打开隔离集。
3. Phase 5/7 桥接仅先影子运行。实测单线程推理与完整服务端采样到求解延迟（目标 ≤20 ms）、reset/重连、时钟跳变、VD 缺失、设备重新佩戴后的状态处理；最终用实机长会话独立真值确认后，才考虑逐设备的受控在线启用。

## 技术依据与适用范围

- [TransPose 原论文](https://arxiv.org/abs/2105.04605)使用时序网络与带置信度的支撑足/网络融合，支持把运动线索作为带质量的观测；它没有证明本项目四腿 IMU 的独立偏航可被 HMD/VD 自动恢复。
- [PIP 原论文](https://openaccess.thecvf.com/content/CVPR2022/html/Yi_Physical_Inertial_Poser_PIP_Physics-Aware_Real-Time_Human_Motion_Tracking_From_CVPR_2022_paper.html)结合神经运动估计与物理约束，支持“网络给候选、约束求解负责稳定性”的分工；本项目缺足部 IMU，不能直接移用其足部假设。
- [KalmanNet 原论文](https://arxiv.org/abs/2107.10043)提供已知状态动力学与学习滤波增益结合的参考；本计划先实现可解释的显式滤波器，再决定是否学习增益。本项目的候选观测网络须另行训练和验证。
- [AMASS 原论文](https://openaccess.thecvf.com/content_ICCV_2019/papers/Mahmood_AMASS_Archive_of_Motion_Capture_As_Surface_Shapes_ICCV_2019_paper.pdf)说明原始语料有大量动作；能否获得适合本任务的长连续序列须以本地文件审计和许可为准。
- [VQF 原论文与实现文档](https://vqf.readthedocs.io/en/stable/)提供休息状态检测和在线陀螺零偏估计的可复用基线；需有原始角速度/加速度，且不能从其 6D 版本推论已获得绝对世界航向。
- [步态 PCA 原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4610524/)指出 PCA 步行轴存在 180° 歧义，需要额外相位/方向条件；本项目四腿 IMU 与 HMD 的组合仍须独立验证。
- [关节链可观测性研究](https://www.sciencedirect.com/science/article/pii/S0967066122000892)表明相对姿态可观测性依赖具体关节运动，因此步态/膝关节约束需有质量门禁，不能视为全时绝对偏航锚点。
