# Phase 8：实机采集与在线迁移

> **状态（2026-10-17）**：待目标硬件就绪；当前不执行在线补偿。数据采集与验收以 [Phase 9 的 ≥30 分钟端点累计误差目标](../phase-09-stateful-bias-model/plan.md)为准。

## 子计划

1. 初始 reset/标定后，采集 4 个下肢 IMU 与 Quest / VD 上身参考的同步 ≥30 分钟连续会话；保存 Mounting、丢包、时间戳和任何中途 reset，发生 reset 则重划会话。
2. 在开始和结束分别建立可追溯的光学或其他独立姿态参考；终点测量必须在再次 reset 之前，明确参考自身误差和时钟同步误差。
3. 在影子模式比对原生求解与候选状态模型，以四路开始→结束偏航误差增长绝对值之和的变化为主；逐帧误差、漂移斜率、骨架误差和足滑只作诊断/安全指标。
4. 通过真实数据回放、超时/断连/Reset 安全检查和端到端时延门槛后，再考虑在线应用修正。

执行结果见同目录 [`results.md`](results.md)。
